# NVP6324 — AHD20_1080P_25P register sequence (porting spec for nvp6324.c)

Validated extraction from the vendor reference (chip-only files) for **channel 0,
AHD 2.0 1080p25, 4-lane MIPI CSI-2 UYVY**. This is the spec to port into
`nvp6324_setup_mipi()` / `nvp6324_setup_channel()` (replacing the M0 stubs).

Format: `{bank, reg} = value`. Slave 0x60 (7-bit 0x30 in the ref; **this board is
0x31**). Bank select = reg 0xFF. 8-bit/8-bit. **Order matters** where noted.

## Critical gotchas (do these right)
- **OMIT the test pattern.** The ref calls `vd_pattern_enable()` unconditionally
  (bank0 0x1C-0x1F=0x1A; bank5/6/7/8 0x6A=0x80) → color bars. Do NOT port it, or we
  get bars instead of live video.
- **Use the net-final values** (List 4) where the EQ stage overwrites a seq value —
  a regmap driver writes each reg once.
- **`h_mask_sel` is bank(0x05+ch) 0x38 bits[3:0]=0x03, NOT bank0 0x8E** (my
  `nvp6324_regs.h` comment was wrong — fix it). `ahd_mode`=bank0 0x08=0x03 ✓,
  `burst_dec_c`=bank5 0xD1=0x30 ✓.
- **Bank-cache bug in the ref** (do the intended thing): CLK_AUTO must clear
  **bank1 0x7C bit(ch)** — the ref accidentally writes it in bank 0x13. Program
  bank1 0x7C[ch]=0 explicitly.
- Bitfield writes = `regmap_update_bits` (RMW): 01/7C[ch], 05/69[0], 05/38[4] &
  [3:0], 00/14[4]+CHID, 05/53[3:2], EQ 00/6C[3:0], bank13 0x30/0x31/0x32
  (clear bit ch & ch+4), bank21 0x3E nibble, bank20 0x01 [2ch +:2].

## Channel-index arithmetic (ch0 → ch1-3)
- per-ch decoder bank = `0x05 + ch`; bank0 color/timing regs `addr + ch`
  (0x00,0x08,0x14,0x20,0x68 families); bank9 H-scaler `addr + 0x20*ch`,
  FSC_EXT_VAL `0x50 + 4*ch`, FSC_DET `0x40+ch`; bank1 clocks `addr + ch`
  (0x84,0x88,0x8C,0xC8,0xCC,0xEC), CLK_AUTO 0x7C bit(ch); bankA/B EQ
  `bank = 0x0A + ((ch)/2)`, `addr = base + (ch%2)*0x80`; MIPI datatype 0x38+ch;
  arb enable `en_param |= 0x11 << ch`.

## LIST 1 — COMMON init (once)

### 1A video_decoder_init
- bank0x04: 0xA0..0xC3 = 0x24 (36 writes)
- bank0x01: 0xCC,0xCD,0xCE,0xCF = 0x64  (later zeroed by 1D — net 0x00)
- bank0x21: 0x07=0x80 then 0x07=0x00 (MIPI reset pulse)
- bank0x0A: 0x77=0x8F, 0xF7=0x8F ; bank0x0B: 0x77=0x8F, 0xF7=0x8F

### 1B mipi_tx_init (1080p / ~1242 MHz) — KEEP THIS ORDER (0x44/0x49 is a lock pulse)
bank0x21:
```
40=B4 41=00 42=03 43=43            (PLL)
11=08 10=13 12=0B 13=12 17=02 18=12 15=07 14=2D 16=0B 19=09 1A=15 1B=11 1C=0E  (D-PHY timing)
44=00 49=F3 49=F0 44=02            (PLL/reset latch pulse)
08=40 0F=01                        (frame-cnt en)
38=1E 39=1E 3A=1E 3B=1E            (VC0-3 datatype YUV422)
07=0F                              (4-lane enable)
2D=01
```

### 1C arb_init
bank0x20: 00=00 ; 40=01 ; 0F=00 ; 0D=01 ; 40=00 ; 00=en_param (0x11 ch0-only, 0xFF all 4)

### 1D disable_parallel
bank0x01: 0xC8..0xCF = 0x00 (8 writes)

### 1E vd_pattern_enable — **DO NOT PORT** (test pattern)
